# Automate what you repeat

## Summary

- Script a task you do repeatedly. ^summary

## Statement

Turn repeated manual steps into a script or a check.

## Why

Manual steps get skipped and done differently each time.

## How it applies

Start with the smallest script that works. Keep it where the team can run it.

## Implications

Routine work becomes reliable, and people spend time on harder problems.
