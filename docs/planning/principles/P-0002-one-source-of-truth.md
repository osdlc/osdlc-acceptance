# Keep one source of truth

## Summary

- Every fact lives in one place; everything else derives from it. ^summary

## Statement

State each fact once. Generate or link to it everywhere else.

## Why

Copies drift apart. Then nobody knows which one is right.

## How it applies

When you find a second copy, replace it with a link or a generated output.

## Implications

Changes happen in one place, and readers can trust what they find.
